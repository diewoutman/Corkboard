# Translations

The frontend uses [Transloco](https://jsverse.gitbook.io/transloco) with one JSON file per language in
`frontend/src/assets/i18n/` (`en.json` is the source language, `nl.json` the Dutch translation).

- Plain nested JSON, so the files can be handed to a translation platform such as Weblate later without conversion.
- Keys are stable, descriptive and grouped by page/area (`tasks.new_list`) — never the English sentence itself.
- In templates: `{{ 'tasks.new_list' | transloco }}`, or `[placeholder]="'…' | transloco"` for attributes.
- In TypeScript: inject `TranslocoService` and call `translate('tasks.errors.load')`.
- Add every new key to **both** files; `i18n-files.spec.ts` fails if their keys differ.
- The language is chosen in the account menu, stored in `localStorage` (`corkboard.language`), and falls back to the browser language, then English. Switching reloads the page so `LOCALE_ID` (used by the `date` pipe) follows.

Not translated yet: everything except the Tasks page and the account menu.
